# 방로그 Plus v1.4 · 수선 요청 기록장

작성·공식 원문 확인: 2026-11-11 (한국 시간). 로컬 구현, 운영 미배포. 기존 DB/GPT/사진 분석/회원 기록 유지.

## 판단
적용 가능하다. 상대방 가입·합의·입주 사진은 입력 조건이 아니다. 사용자가 남긴 사실, 상대방 주장, 실제 전달 시각, 앱 저장 시각을 분리한다. 공식 조정사례를 승소·책임 확정 기준으로 사용하지 않는다.

## 구현 범위
홈·분석 결과·계정 화면의 **수선 요청·퇴실 기록장** → 새 수선 기록 → 발견·요청 → 연락·응답 → 퇴실·비용 → 기록 요약.

- 발견: 하자 위치, 최초 발견 시각, 사용 지장, 재발, 업체 점검, 사진·영상.
- 연락: 임대인이 이미 알고 있었는지와 그 정황, 여러 건의 실제 전달 시각·채널·내용, 응답 시각·내용. 빈칸을 현재 시각으로 자동 채우지 않음. 앱 저장/기록 생성 시각은 별도 표시하며 전달 증명을 주장하지 않음.
- 비교: 기록 하나당 동일 위치의 입주/퇴실 사진과 상태. 입주 사진 없음 선택, 메모·기존 메시지 등 대체 자료 안내. 보증금 공제 사유는 임대인 주장으로 표시. 특약·견적·지출·영수증·업체 소견을 같은 화면에 연결.
- 요약: 입력 사실, 추가로 필요한 자료, 공식 출처, 복사. 사진·영상·PDF 개별 내려받기와 기록 전체 삭제.
- 브라우저 IndexedDB 명시 저장. 새로고침 후 기록과 파일 복원. 파일당20MB, 기록당30개/100MB. JPEG/PNG/WebP, MP4/MOV/WebM, PDF. 입주/퇴실 비교는 사진만 허용. 잘못된 형식/초과 용량 거부, 저장 실패 시 성공 표시 없이 입력 유지.

## 저장·개인정보 경계
기록장은 이 기기 브라우저 전용이며 상대방 가입이나 본인 로그인 없이 사용한다. **서버 회원 기록과 동기화하지 않는다.** 원본을 서버나 GPT로 전송하지 않는다. 기존 사진 분석 요청은 별도이며 기존의 원본 미저장 방침을 유지한다. 이번에 새로 허용한 것은 수선 증빙의 동의 기반 기기 내 보관이다.

브라우저 데이터 삭제/기기 변경 시 사라질 수 있다. 원본은 별도 보관하고 첨부 내려받기·요약 복사를 제공한다. 자동 백업/다른 기기 복원 기능은 없다. 공용기기 사용 시 기록장에서 삭제해야 한다. 계정 로그아웃/기존 세션 삭제는 기록장 삭제가 아니다. 저장 데이터는 별도 암호화되지 않으며 같은 브라우저를 사용하는 사람은 볼 수 있다.

개인정보 안내와 consentVersion을 2026-11-11.v5로 변경. 서버에는 여전히 기존 동의/입력 검사를 적용하고 새 기록장 내용은 전송하지 않는다. 저장은 원자적 IndexedDB 트랜잭션이며 저장 중 조작을 막는다. 작성 중 앱 내 다른 화면으로 이동해도 컴포넌트 상태를 유지하되 브라우저 종료 전에는 명시 저장이 필요하다.

## 팀 테스트 순서
1. 로그인 없이 기록장 진입 → 욕실 천장 누수와 발견 시각·사용 지장 기록, 사진 첨부.
2. 이 기기 저장 동의/저장 → 실제 전달 시각이 자동 생성되지 않았는지 확인.
3. 연락 추가 → 카톡 전달 시각과 내용 → 임대인 응답 시각·내용 기록.
4. 입주 사진 없음 선택 → 기존 하자 메모·퇴실 사진·공제 주장·특약·견적·영수증·업체 소견 연결.
5. 저장 후 새로고침 → 같은 기록/첨부 복원 → 요약 사실/미확인 자료/관련 출처 확인.
6. 기록 삭제 → 저장 기록과 첨부 삭제 확인. 계정 로그아웃과 로컬 기록 삭제를 혼동하지 않기.
