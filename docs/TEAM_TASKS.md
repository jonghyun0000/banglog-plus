# 팀 역할 제안 — 합의 전 초안

사람 팀원이 이미 합의하거나 수행했다는 기록이 아니다. 조장은 이종현, A/B/C/D는 팀원 배치용 자리표시자다.

| 제안 담당 | 다음 작업 | 제안 검토자 | 완료 기준 |
| --- | --- | --- | --- |
| 조장 이종현 | 범위·통합·발표에서 데모와 실연동 구분 | D | PRD/HANDOFF와 발표 내용 일치 |
| A | 실기기 폼·키보드·200% UI 확인 | D | iOS/Android 기록, 문제 수정과 재검증 |
| B | 승인된 DB 환경·역할·TLS·정리 scheduler·백업 검증 | 조장 | 권한·삭제·만료 통합 테스트 통과 |
| C | 출처·규칙·60개 사례의 법률가 검토 의뢰, 명시적 모델 평가 | 조장/B | 검토자·범위·버전 기록, 부적합 결론 보류 |
| D | 처음 보는 대상 사용자 5명 3초 테스트, 전체 흐름 관찰 | A | 익명 결과와 실패 관찰 기록, 허위 성과 없음 |

외부 법률 검토자·토스 담당자·AI 키 발급자는 정해지지 않았다. 실제 회의·인터뷰·팀원 참여·커밋은 만들어 기록하지 않는다.
