# 인계 — 2026-10-15

## 완료한 로컬 범위
지정된 빈 폴더에 React/TypeScript/Vite + Fastify + Zod 독립 앱을 구현했다. 세 문제 유형의 관찰 입력·7단계 질문·수정·분석·조건부 결과·연락 문구 편집/복사·선택 피드백·기록 삭제를 연결했다. 가입·임대인 응답·사진은 필요 없다.

즉시 위험 안내, 개인정보 마스킹, 입력 버전, 세입자/상대방/전해 들은 기사 소견, 상충·모름·제3자 확인, 중립 조건, 출처 ID/버전 검증, 서버 전용 OpenAI 어댑터, 게스트 토큰·RLS·만료·삭제 경합·멱등성·제한·예산 예약을 구현했다.

기본 `npm run dev`는 mock + memory. `npm run db:local` 및 `npm run dev:db`는 mock + 실제 로컬 PostgreSQL이다. 서버 코드는 원격 Supabase 직접 PG 연결에 사용할 수 있지만 원격 연결·적용은 하지 않았다. `npm run build` 성공은 토스 bundle이나 출시가 아니다.

## GitHub / Vercel 배포 추가 작업 (2026-10-15)

사용자가 GitHub 업로드와 Vercel 배포를 명시적으로 요청했다. 별도 `banglog-plus` 저장소/프로젝트로 브라우저 체험판을 배포한다. 기존 방로그의 저장소/배포는 변경하지 않는다.

`build:demo`는 브라우저 메모리 전용 mock을 선택한다. 서버 API, 실제 AI, 원격 DB를 호출하지 않는다. 저장/삭제/선택 피드백 고지가 이 동작과 일치한다. 공통 순수 규칙은 `shared/analysis.ts`에 두고 서버도 같은 함수를 사용한다. 서버 실행과 원격 DB 준비 상태는 기존과 동일하다. 배포 결과는 `DEPLOYMENT.md`를 참조한다.

배포 작업에서는 브라우저 검증을 위해 로컬 개발 서버를 종료했다. 다시 실행하려면 `npm run dev:db`를 사용한다.
