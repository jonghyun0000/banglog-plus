# 제품 요구사항

## 대상과 문제
대학생 자취생과 사회초년생을 우선 설명 대상으로 하되 모든 대한민국 주택 전·월세 세입자가 이용한다. 학교·직장·소득·학생증을 수집하지 않는다. 임대인은 가입자가 아니라 연락 상대방이다.

세입자가 집 수리 문제를 설명하고, 점검 요청 상대와 비용 부담을 가르는 조건을 이해하고, 다음 행동과 차분한 연락 문구를 얻는 것이 P0 목표다. 책임 안내는 사용자 편들기가 아니라 사실·조건·검증 자료에 따른다.

## 범위
곰팡이·결로, 누수, 보일러, 벽지·장판 손상, 배수 문제, 옵션 제품 고장. 사진 없이 텍스트만으로 완료. 역할 선택, 강제 계정, 채팅, 상대방 초대, 자동 발송, 금액·분담률, 결제, 기사 매칭, 관리 대시보드, 전체 계약 OCR, 전세사기·소송 기능은 제외한다. 사진 분석은 P1이며 버튼도 노출하지 않는다.

## 완료 기준
- 홈에서 대상·핵심 기능·시작 동작이 보이고 단일 주요 CTA가 있다.
- 문제 선택 후 7개 단계, 선택 답변·모름·선택 설명, 입력 확인·수정, 버전 연결을 제공한다.
- 위험 안내는 입력 즉시, 일반 결과는 조건을 요약과 함께 표시한다.
- 점검 상대와 비용 방향 분리, 최대 3개 다음 행동, 근거·입력 접기.
- 문구 편집·복사 성공 판별·수동 복사, 선택 피드백, 세션 삭제.
- 서버 토큰 소유권·만료·멱등성·출처 검증·예산 한도를 테스트한다.
- 수업 로컬 MVP와 실제 AI/원격 DB/공개 출시를 구분한다.

3초 이해 테스트의 목표는 첫 사용자 5명 중 4명이 대상·기능·시작을 이해하는 것이다. 현재 사람 테스트는 미실행이며 성공률을 주장하지 않는다.

## 2026년 10월 확장

팀 피드백에 따라 유형을 6개로 확장한다. 7개 단계는 유지하며 증상 선택, 입주 당시 상태, 원래 제공된 시설 여부를 연결한다. 벽지·장판의 찢어짐·찍힘은 사용자가 선택하는 기록 기능이며 자동 영상 판독이 아니다. 통상 마모라는 설명도 선택할 수 있지만 책임 확정으로 변환하지 않는다.

결과는 유형별 기록·점검 목록과 선택 증상이 담긴 연락 문구를 제공한다. 원문을 확인한 판례는 교육용 참고 영역에 표시하고, 자동 분석 결론의 인용 근거와 분리한다. 신축의 임대차 수리 상황 정리는 지원하되 시공사 하자보수 청구·하자보증금·형사책임은 제외한다.

현재 제출물은 독립 웹 데모다. 기존 플랫폼 입점·제휴는 후속 제안이며 실제 연동된 것처럼 표현하지 않는다. 차별화와 검증 계획은 TEAM_FEEDBACK.md, 출처별 확인 상태는 RESEARCH.md에 기록한다.
