# 2026-11-17 · 저장한 최종 결과 복원과 법률 링크 수정

## 변경 이유와 동작

- **내 기록 → 최종 결과 보기**: 요약 텍스트를 펼치는 대신 실제 최종 결과 컴포넌트를 재사용한다. 저장된 입력, 답변, 사진 관찰, 다음 대응, 조건별 안내와 출처를 표시한다. 한국어·영어 결과를 지원한다.
- 기록 조회는 새 GPT 요청이나 기록 덮어쓰기를 하지 않는다. 저장 당시 답변을 표시하며 새 분석·중복 저장 버튼은 숨긴다. 저장된 연락 문구를 수정해 복사할 수 있고 목록으로 돌아와 다른 기록을 열 수 있다. 문구 편집은 기존과 같이 복사용이며 저장 원본을 바꾸지 않는다.
- 회원 소유권 검사, 저장 API·스키마와 DB, 기존 로그인·기록 삭제·사진 처리 경로는 유지한다. 로그아웃/세션 변경 시 선택한 기록과 목록을 지운다.
- **법률 링크**: `lsSideInfoP.do`로 연결하던 민법 링크의 HTTP 404를 신규 브라우저에서 재현했다. `lsiSeq=284415`에 한해 동일 시행일(2026-03-17)·법률 제21454호를 명시한 공식 전체 본문 주소로 표시한다. 승인된 자료·문구·URL 원본은 수정하지 않는다. 기존 회원 기록도 화면에 표시할 때 주소를 보정한다. 알 수 없는 법령 버전과 판례 주소는 임의 변환하지 않는다.
- 공식 조문 623·634·626·615·654와 판례 2023다249661·2018다291347를 쿠키 없는 브라우저에서 열어 HTTP 200뿐 아니라 해당 조문/사건번호의 본문을 확인했다. 다른 사용자 노트북 자체나 학교 네트워크는 직접 검사하지 않았다.

## 이번 배포에 함께 포함하는 앞선 요청

- 로고 클릭으로 홈 이동, 대기 중인 분석의 늦은 응답에 의한 화면 전환 방지.
- 한·영 결과 상단의 지금 할 일·연락 대상·비용 확인 요약, 질문 구간 표시.
- 위험 신호가 없고 교체형 전구 한 개가 꺼진 경우에만 선택 질문을 줄이는 경로. 복수 조명·일체형·교체 후 고장·위험 신호는 제외한다.
- 로컬 임시 산출물 `.local`을 앱 린트 범위에서 제외. 앱 코드 검사는 유지한다.

## 검증

검증 로그와 공식 링크 접속 보고서는 `.local/history-release/`에 보관한다.

- 타입 검사 통과, 린트 통과, 단위 검사 227개 통과, 격리 DB 검사 32개 통과, 브라우저 전체 검사 62개 통과, 운영 빌드 통과.
- 저장 결과 화면을 360×640, 390×844, 1440×900에서 검사: 가로 넘침 없음, axe 접근성 위반 0건. 결과 재열기·문구 복사 편집·한영 전환·로그아웃/삭제 검사 포함.
- 회원 브라우저 검사는 인증/저장 응답을 모의 처리한다. 실제 사용자 회원 데이터를 테스트를 위해 변경하지 않는다.
- 기존 긴급 안전 차단, 배수 분기, 사진 실패 시 대체 안내, 기록장 재열기, 비밀번호 재설정 회귀 검사를 포함한다.
- 초기 전체 브라우저 실행 60/62 통과 후, 변경된 화면의 버튼 위치와 보정된 URL을 검사하도록 기대값을 수정했다. 검사 범위를 축소하거나 새 URL을 건너뛰지 않았다.

### 운영 확인 후 공식 본문 경로 보강

한글 법령 주소는 초기 새 브라우저 검사에서 열렸지만 후속 운영 새 창 검사에서는 본문이 비어 있는 경우를 재현했다. 동일 법령 ID를 유지하는 `https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=284415#J623:0` 전체 본문 경로로 보강한다. 표시 문구나 승인 자료는 바꾸지 않는다. 단순 HTTP 200 대신 조문 본문·시행일의 실제 표시를 확인한다.

PR #15 운영에서 GPT live 응답 1건(기본 안내 대체 아님, 연결 근거 3건), 회원 기능 활성·DB 연결 준비 상태를 확인했다. 운영 화면의 저장 기록 조회는 모의 회원 응답으로 360·390·1440px에서 새 AI 호출 없음·가로 넘침 없음·axe 위반 0건을 확인했다. 실제 회원 기록은 수정하지 않았다.
