# 2026-11-17 · 위험신호 직접 입력과 분석 진행 표시

## 사용자 요청과 변경

- 위험신호 선택지를 `지금 위험 신호는 없어요` 하나와 직접 입력란으로 정리했다. 기타 상황·확실하지 않은 내용은 240자 이내로 적을 수 있다. 입력 중 자동으로 다음 화면으로 넘어가지 않는다.
- 직접 적은 가스 냄새·불꽃·감전 등 기존 감지 대상은 화면과 서버에서 검사한다. 경고는 입력란 아래에 표시하고 다음 단계 차단·119 연결을 유지한다. 일반 자유 문장의 모든 위험을 이해하는 AI 판정기는 아니다.
- `safetyDescription`은 선택 필드다. 과거 safety 값과 저장 기록은 계속 읽는다. 새 문장은 개인정보 마스킹 후 검토 화면, 분석 맥락, 사용자 진술과 기존 기록 JSON에 포함한다. DB 구조 변경은 없다.
- 분석을 누른 직후 세션 준비부터 회전 표시를 보여준다. 원과 경과 시간이 계속 갱신되며 30초가 지나면 오래 걸리고 있다는 안내를 추가한다. 임의의 완료율이나 진행 단계를 표시하지 않는다.
- 기기의 동작 줄이기 설정에서 모든 애니메이션을 중단하던 규칙에 작은 로딩 표시만 느린 회전 예외를 두었다. 취소·홈 이동과 늦게 도착한 응답 무시 기능은 유지한다.
- 한글·영어에 적용한다. 영어의 ‘Sparks are coming…’ 표현도 기존 위험 감지에 포함했다. 검토 화면에서 자유 입력 문장이 두 번 표시되던 중복도 제거했다.

## 검증

타입 검사·린트·단위 230개·격리 DB 32개·빌드 통과. 전체 브라우저 검사 66개 통과(360×640·390×844·1440×900 흐름 및 접근성 검사 포함). 변경 파일 포맷 검사도 통과했다. 최초 실행의 영어 화면 검사는 삭제한 선택지를 아직 누르도록 되어 있어 중단한 뒤 직접 입력하는 흐름으로 수정하고 전체를 재실행했다. 운영 배포 결과는 Notion 같은 날짜 기록에 이어 정리한다.

회귀 검사에는 옛 입력 호환성, 개인정보 마스킹, 위험 문장 차단, 저장 기록 스키마 보존, 한·영 검토, 세션 요청 대기 중 회전·경과 시간·취소, 동작 줄이기 설정을 포함한다. 화면 검사는 브라우저 모바일 크기 시뮬레이션이며 실제 휴대폰 실물 검사는 아니다. 이번 검증은 모의 AI를 사용하며 실제 유료 GPT 호출을 새로 수행하지 않는다.
