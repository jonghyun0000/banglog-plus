# 방로그 Plus 자료 검증과 경쟁 서비스 조사

확인일: 2026년 10월 21일. 팀에서 제공한 판결·기사·상담 사례를 구분하고, 제품에 반영할 수 있는 범위를 정리했다. 판결 요지와 일반 안내는 개인 사건의 책임을 확정하지 않는다. 원문 기술 확인과 법률 전문가 검토는 별개이며, 전문가 검토는 아직 받지 않았다.

## 일반 법령과 안내

[민법 제623조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0623&lsiSeq=284415&urlMode=lsScJoRltInfoR)는 계약 중 목적물을 사용·수익하는 데 필요한 상태 유지 의무의 일반 원칙이다. [찾기쉬운 생활법령의 임대인 권리·의무 안내](https://easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=4&cciNo=2&cnpClsNo=2&csmSeq=629&popMenu=ov)는 수리 정도·사용수익에 미치는 영향·약정 확인의 자료다. 새 유형에도 이 일반 출처를 내부용으로 연결하되 사람 검토 대기·공개 자동 인용 금지를 유지한다.

## 경쟁 서비스의 확인된 기능

공식 공개 웹페이지를 기준으로 비교했다. 로그인 후 앱 기능·지역별 제공 여부·실제 예약 완료까지 조사한 것은 아니다. 확인되지 않은 기능은 ‘없음’으로 단정하지 않는다.

수리 연결 자체는 이미 존재하는 기능이므로 ‘최초’·‘유일’·‘경쟁 없음’을 발표 근거로 쓰지 않는다. 위 비교를 바탕으로 방로그의 제안은 **세입자의 사실 정리 → 필요한 점검 자료 확인 → 중립적 연락 문구 작성**이다. 이는 제품 기획상 판단이며 경쟁 우위를 실증한 결과는 아니다.

## 추가 조사 과제

- 자리톡·당근·다방의 실제 앱에서 수리·민원·견적 흐름과 진입 위치를 확인한다.
- 판례 원문이 확보되지 않은 수원지법 사건은 주문과 이유를 먼저 대조한다.
- 신축 하자보수는 분양자·임차인·시공사의 역할, 청구 대상과 기간을 별도 조사한 뒤 확장 여부를 결정한다.
- 인터뷰에서 ‘비용을 확정해 주는 도구’로 오해하는지, 어떤 기록을 준비해야 하는지 이해하는지 확인한다.
