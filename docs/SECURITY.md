# v1.4 개인정보 변경 · 2026-11-11
수선 요청 기록장은 사용자의 별도 동의 후 IndexedDB에 기록·사진·영상·PDF 원본을 기기 내 저장한다. 기존 GPT 사진 분석의 원본 서버 미저장은 유지한다. 기록장은 서버/AI로 전송하지 않으며 회원 기록과 별개이다. 동의 버전2026-11-11.v5. 기기 공유자 접근 가능, 브라우저 데이터 삭제 시 소실 가능, 로그아웃/세션 삭제와 별도로 기록장에서 삭제해야 함을 고지한다. 파일형식·20MB/개·100MB/기록·30개 제한. Blob URL은 화면 수명 종료 시 폐기하고 HTML/SVG 파일을 허용하지 않는다. 새 법률 초안은 2인 팀 검증 전 DB/AI 미반영. 자세한 범위와 한계는 V1_4_REPAIR_RECORDS.md.

아래는 초기 보안 문서이며 현재 구현과 차이가 있는 역사적 내용(이미지 미수집 등)은 위 변경 기록과 최신 코드가 우선한다.

# 보안·개인정보·한도

## 경계
32바이트 CSPRNG 게스트 토큰 발급, DB에는 SHA-256만 저장한다. 24시간 만료이며 세션 삭제는 철회와 동일하게 접근을 끊는다. 브라우저 메모리 외 저장·URL·공유·로그·결과·문구에는 토큰을 넣지 않는다. 새로고침 시 접근권을 잃지만 서버 데이터 삭제와는 다르다.

모든 결과·피드백·이벤트·취소·삭제는 토큰으로 인증하고 소유자를 확인한다. CORS는 허용 Origin 제한일 뿐 인증이 아니다. trustProxy=false라 임의 X-Forwarded-For로 제한을 피할 수 없다. reverse proxy 배포 시 실제 네트워크 구조에 맞춘 IP 신뢰 설정과 추가 제한 계층이 필요하다.

## 입력과 로그
상황 1000자, 계약 문장 300자, HTTP body 16KB, Zod strict schema. 연락처·주민번호·이메일·일부 계좌 형식·상세 주소 패턴을 클라이언트 안내와 서버 마스킹으로 처리한다. 완전한 탐지를 주장하지 않는다. 이미지·계약서 전체·학교·소득은 수집하지 않는다.

Fastify request logger 비활성화, 오류 응답은 고정 코드/한국어 문장만 사용. OpenAI 원문 오류·PG 오류·환경값을 출력하지 않는다. 서버 시작 실패도 비밀값 없이 안내한다. API·브라우저 번들의 비밀키 패턴을 검사한다. 원격 DB·proxy·공급자 로그의 설정과 백업 정책은 별도 확인 대상이다. 실제 운영 전 상세 error/query/body/header 로깅을 금지하고 검증한다.

React가 텍스트를 escape하며 dangerouslySetInnerHTML을 사용하지 않는다. 임의 URL은 서버에서 fetch하지 않는다. 출처 링크는 서버 허용 목록, 모델 도구 없음. 비밀키 입력 화면 없음.

## 한도와 비용
- IP별 전체 요청 240/분, 세션 생성 12/시간; 세션별 분석 20/시간.
- 기본 외부 AI 30호출/일, 300000 예약 토큰/일, 동시 분석 2, 출력 토큰 800.
- 공급자 timeout 25초, SDK 자동 재시도 0. 거절/잘못된 JSON/429/timeout/저장 실패를 구분한다.
- PostgreSQL에서 일별 예약을 advisory lock 아래 원자 처리. 입력 UTF-8 바이트+스키마 여유분+최대 출력 토큰을 보수적으로 예약한다. 가격 설정은 입력/출력 단가/일예산 셋이 모두 유효해야 한다.
- 가격 미설정은 실제 비용 미산정이며 호출·토큰 제한은 유지한다. 데모 비용은 0으로 구분해 live 통계에서 제외한다.
- 실패/취소의 불확실한 소비 예약을 환급하지 않는다. 실제 청구액 일치나 중단 시 공급자 비용 취소를 보장하지 않는다.
- 단일 API 인스턴스 lock으로 프로세스별 동시성 제한이 여러 배가 되는 것을 막는다. 메모리 rate-limit은 재시작 시 초기화된다. 공개 확장은 공유 rate-limit와 지출 알림을 추가해야 한다.

## 삭제·보관
게스트·입력·결과·피드백·세션 이벤트는 cascade 삭제. 불변 공개 근거와 사용자 식별 없는 일별 예산 누계는 별도 유지한다. 만료 즉시 접근 불가, 물리 삭제는 1분 정리 주기와 서버 가용성에 따르며 운영 scheduler는 미배포다. 삭제 중 늦은 응답이 데이터를 다시 만들지 않는지 메모리와 실제 PostgreSQL에서 검사했다.

필수 처리 확인과 선택 피드백을 분리했다. 장기 저장·연구 동의 기능은 없고 원문 연구 재사용은 비활성화다. OpenAI store:false를 사용하지만 악용 모니터링 보관과 지역·국외이전·조직 설정은 공개 전 확인해야 한다. 동의 문구는 법률가 검토 전 초안이다.

## 공개 전 필요한 검토
법률 기준/출처 사람 검토, 개인정보 고지·공급자 계정 조건·백업/로그, 만료 scheduler, 실기기 접근성, 실제 모델 성능·가격, 토스 정책/입점 가능 여부. PUBLIC_LAUNCH_ENABLED=true만으로 해제되지 않도록 현재 서버는 차단한다.


## 2026-11-11 · 새 법률 7건의 관리자 단독 승인
사용자 명시 요청으로 v1.4 repair 법률 7건에 관리자 단독 승인 경로를 추가했다. 팀원 2인 검증을 했다고 기록하지 않는다. 이종현 관리자 승인 일자·유형·문구 스냅샷은 shared/repair-admin-approvals.json. 문구·범위·출처·버전 변경 시 재승인, 미등록 출처 거부. 기존 원문/이용조건/전문가 검토/외부AI권한 검사는 유지한다. 새 자료 운영 등록·원격 DB 변경·배포·실제 GPT 호출은 하지 않았다. 기존 운영 판례와 공유 인계서의 미등록 추가 후보는 이번 7건 승인 범위 밖이다.
