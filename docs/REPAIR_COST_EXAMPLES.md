# 결과 상단의 수리비 사례 · 2026-11-12

결과 첫 화면에서 현재 상황과 가까운 시공 사례의 공개 예산을 확인할 수 있다. 비교할 시공 사례가 없으면 가까운 참고 견적의 작업명과 금액을 표시한다. 상단의 전체 건수 링크를 누르면 바로 아래 수리비 목록으로 이동한다. 증상과 작업 범위가 가까운 자료와 같은 유형의 다른 작업을 위에 놓고 48건 모두 펼쳐서 표시한다. 자세한 대응과 판단 근거는 상단에서 바로 이동할 수 있다.

| 등록 자료                 |   수 | 화면 표기                                  |
| ------------------------- | ---: | ------------------------------------------ |
| 숨고 개별 시공 포트폴리오 | 18건 | 업체 공개 예산 · 작업 범위 · 지역 · 게시월 |
| 업체 및 플랫폼 견적 안내  | 29건 | 작업 단위별 참고 금액                      |
| 당근알바 부분 보수 의뢰   |  1건 | 여러 작업의 의뢰 게시 금액                 |

기존 첨부 자료 3개에서 채택한 9건과 범위를 보완한 9건을 모두 사용한다. 새 [개인조사](https://app.notion.com/p/4159ed972828801b80bae9440aa499b2) 자료는 원문의 작업 범위와 금액을 대조했다. 곰팡이 제거와 단열 보강, 누수 탐지와 수리, 벽지·장판의 부분 보수와 전체 시공을 구분한다. 같은 가격이라도 출장비, 건당 의뢰 금액, 작업 견적의 의미를 각각 표시한다. 노션에 적힌 벽·천장 누수의 35만~80만 원과 벽지 소형 손상의 5만~15만 원은 연결 원문에서 같은 조건의 금액을 확인하기 어려웠다. 앱에는 원문에 확인되는 범위와 해당 작업명을 사용했다.

시공 사례 18건은 [수리비 목록](../src/features/analysis/repair-cost-cases.ts), 추가 참고 금액 30건은 [견적 및 의뢰 자료](../src/features/analysis/repair-price-references.ts)에서 읽는다. 각 자료에 원문 링크를 제공한다. 상단 공개 예산 범위는 일치하는 시공 사례에서 계산한다. 실제 결제액과 지불 주체는 확인되지 않았다. 이 자료는 결과 화면용이며 GPT의 법률 근거와 별도로 관리한다. 활성 넘침과 안전 우선 결과에서는 비용을 숨긴다.
