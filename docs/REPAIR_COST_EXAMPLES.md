# 상황별 수리 비용 사례 · 2026-11-12

결과 화면 하단에서 비교할 만한 작업을 최대 두 건 보여준다. 카드에는 업체 공개 예산, 시공 범위, 지역, 게시월, 숨고 원문을 표시한다. 작업 범위가 다른 사례의 가격을 평균 내거나 현재 견적을 추정하지 않는다.

첨부 자료 3개에는 개별 포트폴리오 링크 38건과 평균 가격 자료 1건이 있었다. 원문에서 작업과 예산을 확인하고 결과 조건에 맞는 팀 조사 9건을 채택했다. 세면대·싱크대·변기·욕실 바닥·여러 곳 배수·장판·가정용 에어컨의 빈 범위를 원문이 확인된 포트폴리오 9건으로 보완했다. 합계 18건이다. 재확인이 어려운 원문, 평균, 상업공간, 개별 하자와 비교하기 어려운 펌프·외부 하수관 작업 등은 제외했다. 수리한 업체가 게시한 예산만 확인했으며 영수증이나 실제 결제액, 비용을 낸 사람은 확인하지 못했다. 게시월은 수리일과 다를 수 있다.

카드는 선택한 증상, 배수 위치와 막힘 범위, 제품 유형을 기준으로 고른다. 예를 들어 세면대 한 곳에는 세면대 트랩 작업을 표시하고, 여러 곳이면 주방과 욕실이 이어진 배관 작업을 비교 사례로 쓴다. 원인이 미확인일 때도 사례에 적힌 원인을 해당 사용자의 원인으로 적용하지 않는다. 활성 넘침과 안전 우선 결과에서는 가격을 표시하지 않는다. 검증된 같은 제품 사례가 없는 냉장고·세탁기 등에는 구체적 금액을 표시하지 않는다. 사례는 결과 화면 전용이며 GPT 입력, 법률 출처, 회원 기록 및 운영 DB에는 추가하지 않는다.

원문 링크와 금액은 `src/features/analysis/repair-cost-cases.ts`에 함께 관리한다. 다음 사례를 추가할 때도 본문에서 실제 작업 범위와 예산 표기를 확인한다. 추후 결제 증빙 자료를 받으면 업체 공개 예산과 표기를 구분한다.

로컬 구현 브랜치 `feature/repair-cost-examples` · 운영 미반영.

검증 결과는 단위·API 220건, 격리 PostgreSQL 32건, Chromium 53건, 로컬 데모 8건 통과다. 타입·린트·포맷과 운영/데모 빌드도 통과했다. 모바일에서 세면대 카드·원문 링크·실제 결제 미확인 문구와, 물이 넘칠 때 비용 카드 숨김을 확인했다. 기존 360×640·390×844·1440×900 브라우저 흐름의 가로 넘침과 접근성 검사도 통과했다.
