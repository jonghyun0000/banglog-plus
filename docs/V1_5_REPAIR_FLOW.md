# 방로그 Plus v1.5 수선 흐름

2026-11-11 로컬 작업. 최신 `origin/main`의 `8393637`에서 `feature/v1.5-repair-flow`를 분리했다. 기존 프로젝트의 작업 파일을 보존하기 위해 별도 worktree를 사용했다. 운영 버전은 v1.4다.

## 흐름과 구현 범위

1. 증상·안전 → 상황 확인 → 자료·검토 순으로 진행한다. 보일러·벽지의 미연락/미점검 경로는 검토 전 질문 화면 7개에서 6개로 줄었다. 원인·출처·상대 주장 화면을 건너뛴다. 점검 여부는 연락 여부와 독립적이고, 실제 답변을 받았을 때 답변 입력을 펼칠 수 있다. 배수의 위치·범위·넘침·약품·해본 조치 분기는 유지한다.
2. 결과의 첫 행동과 연락 상대를 먼저 보여주고, 시설 노후·사용 중 손상·외부 또는 불명 원인별로 확인할 자료와 다음 행동을 제시한다. 해당 응답에서 검증된 인용이 있으면 연결하고, 근거의 적용 범위를 표시한다. 책임 비율은 산정하지 않는다.
3. 첫 수선 요청, 점검 후 비용 협의, 답변 지연·거절 후 재요청 문구를 따로 편집·복사한다. 발견일을 발생일로 바꾸지 않으며, 실제 입력의 소견·연락 상태를 활용한다. 복사 실패 시 직접 선택할 수 있고, 초안 재설정에는 확인이 필요하다. 이름·호수는 현재 화면의 복사 미리보기용이다.
4. 결과와 기록장에서 중립적인 기사 질문을 고르고 복사한다. 기록장에 실제 점검 답변·항목별 비용·첨부 증빙을 구분해서 보관한다. 사진 분석 미사용·실패와 무관하게 유형별 촬영 항목과 목적을 확인할 수 있다.
5. 결과 또는 편집한 문구에서 기록장으로 이동해 가져올 내용을 확인한다. 기존 기록을 선택하면 빈 필드만 채우며 연락·파일·기존 입력을 보존한다. 같은 분석의 초안을 바꿀 때는 기존·새 초안을 미리 보여준다. 가져온 사진은 추가 선택 및 기기 저장 동의 후 저장한다. 신규 연결은 실제 연락의 시각·채널을 만들지 않는다.
6. 추가 소견이나 응답을 선택하면 전송할 답변을 검토하고 새로 처리 확인을 거친다. 재안내 결과는 같은 기록에 명시적으로 추가할 수 있고 이전 결과를 함께 열어본다.

## 파일과 데이터 경계

| 기능 | 변경 위치 |
| --- | --- |
| 질문·검토·위험 감지 | `shared/questions.ts`, `shared/drain.ts`, `shared/safety.ts`, `shared/schema.ts`, `src/features/questions/{Questions,Review}.tsx` |
| 조건과 근거·문구·촬영 | `shared/analysis.ts`, `src/features/analysis/{Responsibility,Result}.tsx`, `src/features/message/Message.tsx`, `src/features/photos/PhotoResult.tsx` |
| 기록장·추가 안내 | `src/app/App.tsx`, `shared/repair.ts`, `shared/repair-guide.ts`, `src/features/repair/{RepairWorkspace,InspectionChecklist}.tsx` |
| API·검색 | `server/routes/app.ts`, `server/sources/retrieval.ts` |

`Intake.details`는 선택 필드이며 기존 API/회원 결과를 계속 읽을 수 있다. IndexedDB의 기존 레코드는 추가 이력·선택 질문·점검 답변·항목별 비용에 빈 기본값을 적용한다. 저장소 이름과 DB 스키마는 그대로 사용한다. 초안과 연결 안내, 첨부는 기기 저장 동의가 필요하다. 분석용 사진은 별도 동의가 필요하고, 기기 기록장에는 사용자가 선택해야 복사된다.

재안내는 이전 답변과 선택한 새 메모를 검토 화면에 표시한다. 마스킹된 소견·응답은 기존 분석의 입력 사실에 포함된다. 기록장 전체·연락 일지·비용 메모·발송 문구·파일·별도 입력한 이름과 호수는 요청에서 제외된다. 처리 고지에 새 필드를 반영해 `consentVersion`을 `2026-11-11.v6`으로 변경했다. 원격 DB 구조와 기존 근거 허용 조건을 변경하지 않았다.
